# VIBE CLICKER — браузерная версия

Монохромный кликер с аккаунтами, бесконечными улучшениями, кланами и сохранением прогресса в PostgreSQL.

## Что внутри

- Node.js 22 + Express 5
- PostgreSQL в продакшене (`pg`), встроенный PGlite для локального запуска
- Сервер проверяет клики и покупки: накрутить баланс через консоль браузера нельзя
- Пароли хешируются через scrypt, сессия — подписанная HttpOnly cookie
- 18 уровней улучшений, каждый можно покупать повторно без лимита
- Кланы до 20 участников, бонус +2% к клику за каждого участника
- Автосохранение прогресса каждые 2.5 секунды и при выходе

## Локальный запуск

```bash
npm install
npm start
```

Открой http://localhost:3000. Без `DATABASE_URL` приложение создаст локальную базу в `.data/` — PostgreSQL устанавливать не нужно.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Строка подключения PostgreSQL. Обязательна в продакшене |
| `SESSION_SECRET` | Секрет для подписи cookie. В продакшене обязателен |
| `DATABASE_SSL` | `true` / `false`, если нужно переопределить автоопределение SSL |
| `PORT` | Порт сервера (по умолчанию 3000) |

## Деплой на Render

В репозитории есть `render.yaml` — blueprint создаёт веб-сервис и бесплатную PostgreSQL.

1. Запушь репозиторий на GitHub.
2. В Render: **New → Blueprint**, выбери репозиторий.
3. Render создаст базу и сервис, подставит `DATABASE_URL` и сгенерирует `SESSION_SECRET`.
4. После первого деплоя проверь `https://<имя>.onrender.com/healthz`.

Бесплатный веб-сервис Render засыпает после 15 минут без запросов; первый запуск после сна занимает около минуты.

## API

- `GET /api/config` — конфигурация игры
- `POST /api/auth/register` — регистрация
- `POST /api/auth/login` — вход
- `POST /api/auth/logout` — выход
- `GET /api/me` — текущий профиль
- `POST /api/click` — пачка кликов
- `POST /api/purchase` — покупка улучшения
- `GET /api/clans` — список кланов
- `POST /api/clans` — создание клана
- `POST /api/clans/:id/join` — вступление
- `POST /api/clans/leave` — выход
- `GET /healthz` — health check
